# AI 真實合成 — 後端設定（約 10 分鐘，只需做一次）

## 1. 申請 fal.ai 金鑰
1. 到 https://fal.ai 註冊（可用 Google 帳號）。
2. 到 Billing 儲值（最低額度即可，FASHN 每張約 US$0.075）。
3. 到 https://fal.ai/dashboard/keys 建立一組 API Key，複製起來。

## 2. 建立 Cloudflare Worker
1. 登入 https://dash.cloudflare.com → Workers & Pages → Create → **Create Worker**。
2. 名稱填 `fitroom-ai`，按 Deploy。
3. 按 **Edit code**，把 `worker.js` 的內容整個貼上取代，按 Deploy。
4. 回到 Worker 的 **Settings → Variables and Secrets**，新增兩筆：
   - `FAL_KEY`（類型選 **Secret**）＝ 剛才的 fal.ai 金鑰
   - `ALLOWED_ORIGIN`（Text）＝ `https://frankf19-19.github.io`
5. 記下 Worker 網址，格式像 `https://fitroom-ai.<你的帳號>.workers.dev`。

## 3. 接上網站
把 Worker 網址貼給 Claude，會寫進 `index.html` 的 `AI_ENDPOINT_DEFAULT` 後重新部署。
在那之前，也可以直接在網站「AI 真實合成 → 進階」欄位貼上網址測試。

## 費用控管
- fal.ai 後台可設每月花費上限（Billing → Spending limit），建議先設 US$10。
- 第三期會加上會員與每日額度，現階段 Worker 只擋來源網域，請勿把網址公開給不認識的人。
